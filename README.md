# 电脑管家 PC-Buddy

**在手机上发一句话或一张照片，电脑就把活干了。**

电脑上跑一个小服务，手机浏览器打开它（iPhone 可以"添加到主屏幕"当 App 用），
发文字或拍照，电脑端的 AI 会真的去操作这台 Windows —— 执行命令、开关软件、
点击输入、看屏幕、读图取字 —— 整个过程实时回传到手机。

---

## 快速开始

### 1. 填 API Key

打开 `config.json`（第一次运行 `start.bat` 会自动生成），把 `api_key` 填上：

```json
"deepseek": {
  "base_url": "https://api.deepseek.com",
  "api_key": "sk-你的密钥",
  "model": "deepseek-chat"
}
```

Key 在 <https://platform.deepseek.com/> 申请。**填完存盘。**

> 用记事本编辑没问题，程序能识别带 BOM 的文件。
> 但请注意：JSON 里不能有多余的逗号，也不能用中文引号。

### 2. 双击 `start.bat`

第一次会自动装依赖。启动后黑窗口里会打印手机访问网址，**并且显示一个二维码**。

如果 Windows 弹出防火墙提示，**要选"允许"**，否则手机连不上。

### 3. 手机连上

手机和电脑连**同一个 WiFi**，然后：

- **用相机扫黑窗口里的二维码**，或
- 在手机浏览器里输入黑窗口显示的 `http://192.168.x.x:8765/?t=...`

### 4. 装到 iPhone（添加到主屏幕）

装完之后桌面上会多一个「电脑管家」图标，点开是全屏窗口、没有地址栏和浏览器工具栏，
跟原生 App 基本一样。**图标已经内置**（蓝色显示器），不需要额外找图。

1. **必须用 Safari 打开**上面那个网址。
   微信、QQ 内置的浏览器**不能用**，它们没有"添加到主屏幕"。
   （如果是在微信里点的链接，点右上角「···」→「在 Safari 中打开」）
2. 确认页面能正常加载出来（能看到聊天界面），否则说明口令不对，先解决这个。
3. 点 Safari 底部中间的**分享按钮**（方框 + 向上箭头）。
4. 在弹出菜单里往下滑，选**「添加到主屏幕」**。
5. 名字会自动填成「电脑管家」，右上角点**「添加」**。
6. 回到桌面，图标已经在上面了。以后直接从桌面点开就行。

**注意**：网址里的 `?t=...` 是访问口令，别弄丢。程序也会把它写进 Cookie 兜底，
所以即使哪次口令丢了，通常也能正常打开。如果确实打不开了，删掉桌面图标，
重新扫一次二维码再添加一遍即可。

### 5. 开始用

然后就可以直接发消息了，例如：

- `打开记事本，写一句"今天下午三点开会"，然后保存到桌面`
- `看看我屏幕上开着什么`
- `把这周的下载文件夹里超过 100MB 的文件列出来`
- 拍一张纸质文件 / Excel 截图 / 报错弹窗，配一句"帮我看看这个"

## 它能干什么

| 工具 | 能做的事 |
|---|---|
| `run_powershell` | 执行任意 PowerShell 命令（装软件、批量处理、查系统信息） |
| `open_app` / `open_url` | 打开程序、文件、文件夹、网址 |
| `screenshot` | 给屏幕截图，并直接显示在手机上 |
| `ocr_image` | 识别图片文字（调用 Windows 自带 OCR，支持中文，离线可用） |
| `mouse` | 移动、单击、双击、右键、滚轮 |
| `type_text` | 输入文字（**中文也可以**，走剪贴板粘贴） |
| `press_keys` | 快捷键，如 `ctrl+c`、`alt+tab`、`win+d` |
| `list_windows` / `focus_window` | 查看、切换窗口 |
| `read_file` / `write_file` / `list_dir` | 读写文件和目录 |
| `wait` | 等待加载 |
| `remember` / `read_memory` | 记住长期偏好（如常用路径），下次自动带上 |

## 安全设计

这东西能真的操控你的电脑，所以做了几层护栏：

1. **危险操作必须手机点头**
   删除、格式化、关机、改注册表、强杀进程等会命中规则，
   手机上弹出确认框，**超时未确认按拒绝处理**。被拒绝后 AI 会收到明确的拒绝回执。

2. **急停按钮**
   手机右上角「急停」随时可点，当前动作立即中止，正在等待的确认一并作废。
   另外鼠标甩到屏幕左上角也会触发 pyautogui 的安全保护。

3. **工作目录围栏**
   写文件默认只能在 `data/workspace` 里。写 `C:\Windows`、`Program Files`
   这类系统目录会弹确认。

4. **访问令牌**
   手机网址带随机口令，局域网里别人不知道口令就访问不了。
   错误口令直接断开连接，不会泄露任何信息。

5. **全程留痕**
   每一步操作都写进 `data/audit.log`，事后可以查它到底做了什么。

> ⚠ 仍然请注意：这套东西的定位是**你自己的电脑、你自己的局域网**。
> 不要把 `8765` 端口直接暴露到公网，也不要把带令牌的网址发给别人。

## 关于"发照片"

DeepSeek 的官方对话模型**看不了图片**，所以照片走这条链路：

```
手机拍照 → 电脑落盘 → Windows 本地 OCR 取字 → 文字进模型上下文 → AI 据此干活
```

对"拍文档、拍表格、拍报错弹窗、拍屏幕"这类场景，效果很好，而且是离线识别。

如果你有支持图片的 OpenAI 兼容模型（比如某个 VL 模型），填上 `vision` 配置就能真正"看图"：

```json
"vision": {
  "enabled": true,
  "base_url": "https://你的接口/v1",
  "api_key": "sk-xxx",
  "model": "某个视觉模型"
}
```

开了之后，照片会同时走"视觉描述 + 本地 OCR"，两边信息一起给模型。

## 常见问题

**手机打不开网址**
1. 确认手机和电脑连的是同一个 WiFi（不是手机流量）；
2. 电脑上 Windows 防火墙是否允许了 Python；
3. 在电脑上执行 `ipconfig`，看"无线局域网适配器"的 IPv4 地址，用它替换网址里的 IP。

**加了主屏幕之后打不开了**
网址里的 `?t=...` 口令别丢。程序也会把口令写进 Cookie 作为兜底。
如果还是不行，删掉桌面图标重新扫一次二维码。

**提示"还没填 DeepSeek API Key"**
编辑 `config.json` 的 `api_key`，存盘，然后**重启 `start.bat`**。

**它做得不对怎么办**
直接发消息纠正它，比如"不对，我要的是 XXX"。它会带着之前的上下文继续。
任务跑偏了就点急停。

**想让它在另一台电脑上跑**
整个 `pc-buddy` 文件夹拷过去，装好 Python 3.10+，跑 `start.bat` 即可。
`data/` 里是历史记录，可以删掉。

## 目录结构

```
pc-buddy/
├── start.bat            一键启动（自动装依赖、打印网址和二维码）
├── config.json          你的配置（存 Key，注意别外传）
├── config.example.json  配置模板
├── server.py            HTTP 服务 + 手机端接口 + 实时日志推送
├── agent.py             大脑：DeepSeek 工具调用循环
├── tools.py             手和脚：所有能对电脑做的操作
├── config.py            配置读写
├── mobile/index.html    手机页面（单文件，无外部依赖）
├── tools/ocr.ps1        Windows 本地 OCR 封装
├── data/
│   ├── workspace/       AI 的默认工作目录
│   ├── uploads/         手机传来的照片
│   ├── shots/           电脑截图
│   ├── memory.md        长期笔记
│   └── audit.log        操作审计日志
└── tests/
    ├── unit_test.py     回归测试
    ├── e2e_test.py      端到端测试（用假模型，不需要真 Key）
    └── mock_llm.py      假的 OpenAI 兼容接口
```

## 自测

不需要真实 API Key 就能验证整条链路：

```bash
python tests/unit_test.py     # 23 项回归测试
python tests/e2e_test.py      # 端到端：起假模型 → 跑任务 → 校验全过程
```

`e2e_test.py` 会验证：工具真的被执行、危险命令确实弹出确认且被拒绝后不会执行、
手机照片的 OCR 结果确实进入了模型上下文、错误口令被拒绝。
跑完自动还原 `config.json`。

## 技术说明

- **零重量级框架**：HTTP 服务用 Python 标准库 `http.server`，
  调用模型用 `urllib`，手机页面是单文件原生 JS。只有鼠标键盘和截图依赖 `pyautogui`。
- **实时推送**：手机端用 SSE（Server-Sent Events）接收执行过程，
  断线自动重连并从断点续传。
- **单任务串行**：一次只干一件事，后面的排队，避免两个任务抢鼠标。
- **上下文管理**：跨任务保留对话历史（默认最近 40 条），
  裁切时保证 `tool_call` 与 `tool` 消息成对，不会切出非法请求。
